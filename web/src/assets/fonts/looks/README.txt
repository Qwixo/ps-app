Fonts for the PS looks (V1.31, src/core/looks.ts FONTS, src/looks/fonts.css). Each is a Latin WOFF2 subset from
the Fontsource packages (npm, version 5.3), unmodified, licensed under the SIL Open Font License 1.1 (the OFL file
next to each). Bundled with the app: nothing is fetched from the internet at run time.
  Atkinson Hyperlegible Next and Mono (Braille Institute), IBM Plex Sans and Mono (IBM), JetBrains Mono (JetBrains),
  Source Serif 4 (Adobe).
