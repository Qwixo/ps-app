Handwriting fonts for the Notebook looks (src/views/notebook.css). All are under the SIL Open Font
License 1.1; each licence file sits next to its font. Fetched from the google/fonts repository (ofl/).

GochiHand-Regular.ttf            Gochi Hand by Juan Pablo del Peral. Shipped unmodified (it has Reserved Font Names).
PatrickHand-Regular.woff2        Patrick Hand by Patrick Wagesreiter. Latin subset, converted to WOFF2.
ArchitectsDaughter-Regular.woff2 Architects Daughter by Kimberly Geswein. Latin subset, converted to WOFF2.
Caveat-Variable.woff2            Caveat by The Caveat Project Authors. Latin subset, converted to WOFF2.

Nothing is loaded from the internet at run time: Vite bundles these files with the app.
