Pixel fonts for Minecraft mode (src/views/minecraft/mc-theme.css). Both are under the SIL Open Font License 1.1;
each licence file sits next to its font. Fetched unmodified from the google/fonts repository (ofl/).

PixelifySans-Variable.ttf   Pixelify Sans by The Pixelify Sans Project Authors (body text, weights 400 to 700).
Silkscreen-Regular.ttf      Silkscreen by The Silkscreen Project Authors (titles).

Nothing is loaded from the internet at run time: Vite bundles these files with the app. Neither is any game's font.
